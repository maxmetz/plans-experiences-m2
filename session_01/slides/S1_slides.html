Comment trouver un code entre les deux extrêmes ?

Trouver le code de 55 °C

Le centre est 50 °C. Le pas du centre au haut vaut 10 °C.
55 est à 5 °C au-dessus : un demi-pas, donc +0,5.

\[x_1=\frac{T-50}{10}=\frac{55-50}{10}=0{,}5\]

D’où vient 0,7 ?

20 °C de plus donnent 14 points de plus.
14 ÷ 20 = 0,7 point par degré.

À mi-chemin, nous ajoutons la moitié de 14 : 7 points.

L’hypothèse

Un même degré supplémentaire apporte le même gain dans la plage étudiée.

2 / 2 · Construire · flèche → pour poursuivre
\[\hat y=\underbrace{20}_{\text{mesure à }40\,°C}+\underbrace{0{,}7}_{\text{gain par degré}}\underbrace{(T-40)}_{\text{degrés ajoutés}}\]
À 50 °C

20 + 0,7 × (50 − 40) = 27 %. Le chapeau sur ŷ signifie « prévu », pas « mesuré ».

Pourquoi commencer par une droite ?

C’est l’hypothèse la plus simple d’un gain constant, à vérifier par d’autres mesures. Deux points la définissent mais ne la valident pas.

Interaction : un réglage modifie l’effet de l’autre

1 / 2 · Comprendre · flèche → pour poursuivre
Comparer les pentes, pas seulement les hauteurs

À 1 h et à 2 h, le gain de température diffère. Les segments non parallèles montrent une interaction dans les résultats observés.

2 / 2 · Construire · flèche → pour poursuivre
Parallèles : même gain

Changer la durée déplace la réponse, mais ne change pas le gain de température. Ce dessin est une prévision additive, pas un troisième jeu de mesures.

\[\Delta_T(t)=2b_1+2b_{12}x_2\]
Interprétation et limite

Si b₁₂ = 0, le gain est identique aux deux durées. Avec du bruit, des pentes légèrement différentes ne prouvent pas une interaction réelle. Les segments relient deux niveaux : ils ne valident pas la forme entre ces niveaux.

Deux réglages : écrire les contributions

À un facteur, nous avions : départ + contribution de la température.

Avec deux facteurs, notre première hypothèse est :
prévision = départ + contribution température + contribution durée.

\[\hat y=b_0+b_1x_1+b_2x_2\]

x₁ et x₂ sont les réglages codés. Les b sont les nombres qui règlent les contributions. Ici b₀ est la prévision lorsque les deux codes valent 0.

Si le gain de température change avec la durée, cette addition simple ne suffit plus : il y a une interaction.

Nous ajouterons plus tard une colonne x₁x₂ pour représenter cette interaction.

Chercher les coefficients qui réduisent les écarts

Pourquoi ne pas additionner les écarts ?

+1 − 1 − 1 + 1 = 0 : les écarts se compensent, pourtant les prévisions ne sont pas exactes.

Les carrés donnent 1 + 1 + 1 + 1 = 4.

\[\hat{\boldsymbol\beta}=\underset{\boldsymbol\beta}{\operatorname{arg\,min}}\ \sum_i\left(y_i-(\mathbf X\boldsymbol\beta)_i\right)^2\]
Ce que cherchent les moindres carrés

Choisir les coefficients qui minimisent cette somme pour le modèle retenu. Un résidu rᵢ = yᵢ − ŷᵢ est observable ; il peut refléter du bruit ou une forme de modèle inadéquate.
